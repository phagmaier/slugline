# Security policy

Security fixes are supported for the latest published Slugline release.

For a vulnerability that could put users or their files at risk, use GitHub's
**Security → Report a vulnerability** private-reporting form for this
repository. Do not open a public issue until the report has been assessed. If
private reporting is unavailable, contact the maintainer through the GitHub
profile linked from the repository rather than publishing exploit details.

Include the Slugline version, distribution, impact, reproduction steps, and the
smallest safe supporting material. **Never attach or paste a private,
confidential, or unreleased screenplay.** Use invented Fountain text.

Ordinary bugs without sensitive security impact belong in the public issue
tracker.
