# fountain — scoped agent notes

Scope: screenplay syntax only. No identity, no history, no I/O. This crate
depends on nothing in the workspace.

Key files: `src/syntax.rs` (recognition rules, the single source of truth),
`src/parse.rs`, `src/serialise.rs`, `src/infer.rs` (`infer_kind`),
`src/emphasis.rs`, `src/model.rs`.

Invariants:

- `fountain` owns syntax; `document` owns identity and history. `document`
  re-exports `fountain`'s kinds rather than declaring its own (ADR 0008).
- Recognition rules live once, in `src/syntax.rs`; the serialiser calls the
  same functions backwards. Never add a second opinion about what a line
  means.
- `infer_kind` is the third caller of `syntax.rs` and must never produce a
  kind the file would not give back: no classification rule the parser does
  not already have (ADR 0011).
- Provenance ranges tile the source exactly, so byte-exact round-tripping is
  a consequence, not a feature. Editing a block drops its provenance and
  nothing else's (ADR 0007).
- `testdata/reference-feature.fountain` is generated by
  `python3 tools/make_reference.py`; never hand-edit it or any corpus file.

Verify: `cargo test -p slugline_fountain`, plus
`python3 tools/make_reference.py --check` after touching syntax, parser or
serialiser.

Governing ADRs: 0007, 0008, 0011. Full rules in `AGENTS.md`; the layer map
in `docs/ARCHITECTURE.md`. When an ADR changes this crate, update this file
in the same change.
